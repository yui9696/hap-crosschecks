# B₀(G) ≠ 0 の有限証明書 — 仕様(2026-09-06)

対象: 有限群 G の Bogomolov 乗数

  B₀(G) := ⋂_{A ≤ G bicyclic} Ker( res_A : H²(G, ℚ/ℤ) → H²(A, ℚ/ℤ) )

(Bogomolov 1987 の元定義。A = ⟨a, b⟩, ab = ba)。本仕様は **この定義そのもの**を有限データで検証する形に落とす。Moravec の再定式化(M(G)/M₀(G)、curly exterior square)や Bogomolov の「全アーベル部分群でも同じ」定理は、検証器の側では **使わない**(生成側の道具としてのみ使う、§4)。

確信度の印: 各主張の末尾に〔高/中/低〕。〔高〕= 本文に証明を書いた、または標準的事実。〔中〕= 標準的だが本文で証明を省いた。〔低〕= 推測・未検証。

実装: `b0_cocycle.g`(GAP 4.15.1)。生成器 `B0Certificate(G)`、検証器 `VerifyB0Certificate(cert[, full])`。走行記録: `b0_cocycle_certs.log`。

## 1. 有限化 — 何を、なぜ、その正確な条件

### 1.1 H²(G, ℚ/ℤ) は有限で、位数は |M(G)|

普遍係数定理: H²(G, ℚ/ℤ) ≅ Hom(H₂(G,ℤ), ℚ/ℤ) ⊕ Ext(H₁(G,ℤ), ℚ/ℤ)。ℚ/ℤ は可除 = 入射的 ℤ-加群なので Ext 項は 0。よって

  H²(G, ℚ/ℤ) ≅ Hom(M(G), ℚ/ℤ) ≅ M(G) (非標準同型)、M(G) := H₂(G,ℤ) = Schur 乗数。

特に exp H²(G,ℚ/ℤ) = exp M(G)。〔高〕

### 1.2 ℤ/e 係数への持ち上げ — 「H²(G,ℚ/ℤ) ≅ H²(G,ℤ/e)」は一般に**偽**

短完全列 0 → ℤ/e → ℚ/ℤ →(×e) ℚ/ℤ → 0(ℤ/e = (1/e)ℤ/ℤ)の長完全列:

  H¹(G,ℚ/ℤ) →(×e) H¹(G,ℚ/ℤ) →β H²(G,ℤ/e) →ι H²(G,ℚ/ℤ) →(×e) H²(G,ℚ/ℤ)

- Im ι = H²(G,ℚ/ℤ)[e](e-捩れ部分)。**ι が全射 ⟺ exp M(G) | e**。〔高〕
- Ker ι = β(H¹(G,ℚ/ℤ)) = β(Hom(G,ℚ/ℤ))。これは一般に 0 でない。反例: G = (ℤ/2)²: H²(G,ℤ/2) ≅ (ℤ/2)³、H²(G,ℚ/ℤ) ≅ M(G) ≅ ℤ/2。〔高〕

したがって正しい言明は「e が exp M(G) の倍数なら ι: H²(G,ℤ/e) → H²(G,ℚ/ℤ) は**全射**で、核は Bockstein 像」である。証明書のコサイクル c: G×G → ℤ/e は **ι[c] ∈ H²(G,ℚ/ℤ) の代表**として扱い、検証器が調べる性質はすべて ι[c] の性質(= c/e を ℚ/ℤ 値コサイクルと見たときの性質)にする。これで Ker ι の存在は問題にならない。

**e の選び方**(生成側の問題であって検証側の信頼点ではない):
- 完全性(B₀ の任意の非零類が表現できる)に必要なのは exp M(G) | e。最小は e = exp M(G)。
- M(G) を計算せずに済ませたいなら e = |G| で常に安全(Schur: exp M(G) は |G| を割る)。〔高〕
- 生成器 `B0Certificate` は M(G)/M₀(G) の巡回因子の位数を e に取る(位数 64・128 の全例で e = 2、243 で e = 3)。

### 1.3 「ℚ/ℤ-コバウンダリ」の有限判定

**補題 1.3.** c ∈ Z²(G, ℤ/e) を正規化コサイクル(c(1,g) = c(g,1) = 0)とし、H ≤ G を部分群、E := e · exp(G) とおく。次は同値:
(a) res_H ι[c] = 0 in H²(H, ℚ/ℤ)、すなわち ∃ f: H → ℚ/ℤ, δf = c/e on H×H;
(b) ∃ F: H → ℤ/E, F(g) + F(h) − F(gh) ≡ (E/e)·c(g,h) (mod E) for all g,h ∈ H.

証明. (b)⇒(a): f := F/E。(a)⇒(b): δf = c/e より e·δf = δ(ef) = 0、つまり ef ∈ Hom(H, ℚ/ℤ)。よって ef の値は (1/exp H)ℤ/ℤ ⊂ (1/exp G)ℤ/ℤ に入り、f の値は (1/(e·exp G))ℤ/ℤ = (1/E)ℤ/ℤ に入る。F := E·f。∎ 〔高〕

(b) は ℤ/E 上の線形方程式系(未知数 |H| 個、方程式 |H|² 個)で、Smith 標準形で可解性が決まる。

### 1.4 bicyclic 部分群への制限 = 交換子対称性

E_c := G × ℤ/e に積 (g,z)(h,w) := (gh, z + w + c(g,h)) を入れる。結合律 ⟺ コサイクル恒等式、単位元 (1,0) ⟺ 正規化、(g,z)⁻¹ = (g⁻¹, −z − c(g,g⁻¹))。Z := {(1,z)} は中心で、1 → Z → E_c → G → 1 の拡大類が [c] ∈ H²(G,ℤ/e)。〔高〕

**補題 1.4.** a, b ∈ G が可換、A := ⟨a,b⟩ とする。次は同値:
(a) res_A ι[c] = 0 in H²(A, ℚ/ℤ);
(b) c(a,b) ≡ c(b,a) (mod e).

証明. ã := (a,0), b̃ := (b,0) ∈ E_c。ãb̃ = (ab, c(a,b))、b̃ã = (ba, c(b,a)) = (ab, c(b,a))。よって ãb̃ = b̃ã · (1, c(a,b) − c(b,a))、すなわち [ã,b̃] = ãb̃ã⁻¹b̃⁻¹ = (1, c(a,b) − c(b,a)) ∈ Z。
(a)⇒(b): c|_A = δf (f: A → ℚ/ℤ) なら c(a,b) − c(b,a) = [f(a)+f(b)−f(ab)] − [f(b)+f(a)−f(ba)] = 0 (ab = ba)。
(b)⇒(a): A の E_c における逆像 Ã = ⟨ã, b̃, Z⟩ は、Z が中心で [ã,b̃] = 1 だからアーベル群。0 → ℤ/e → Ã → A → 0 はアーベル群の拡大で、ℤ/e ↪ ℚ/ℤ に沿った押し出しは A の ℚ/ℤ による**アーベル**拡大、ℚ/ℤ は入射的なので Ext¹_ℤ(A, ℚ/ℤ) = 0 で分裂する。押し出しの類は ι(res_A [c]) なので 0。∎ 〔高〕

系: Ã の導来部分群は ⟨[ã,b̃]⟩(Ã/⟨[ã,b̃]⟩ は二元生成で可換)。したがって A = ⟨a,b⟩ に対する条件は生成対 (a,b) 一組の検査で尽きる。**すべての可換対 (a,b) を走れば、すべての bicyclic 部分群を尽くす**(|G|² 回の検査)。1-コチェイン f_A を証明書に含める必要はない。〔高〕

### 1.5 非自明性の二つの有限判定

**補題 1.5.** 次は同値: (a) ι[c] ≠ 0 in H²(G,ℚ/ℤ); (b) 補題 1.3(b) の系が H = G で**非可解**; (c) Z ∩ [E_c, E_c] ≠ 1。

証明. (a)⟺(b) は補題 1.3。(a)⇒(c) の対偶: Z ∩ [E_c,E_c] = 1 とする。Z は E_c^{ab} に単射で入るので、ℚ/ℤ の入射性から包含 Z ↪ ℚ/ℤ は準同型 φ: E_c → ℚ/ℤ に延長する。切断 s(g) := (g,0) に対し c(g,h)/e = φ(s(g)s(h)s(gh)⁻¹) = φs(g) + φs(h) − φs(gh) なので c/e は ℚ/ℤ-コバウンダリ、ι[c] = 0。(c)⇒(a) の対偶: ι[c] = 0 なら押し出し E_c ×_Z ℚ/ℤ ≅ G × ℚ/ℤ で、[E_c,E_c] の像は [G,G] × 0 に入り ℚ/ℤ と交わらない。E_c → 押し出し は単射なので Z ∩ [E_c,E_c] = 1。∎ 〔高〕

(c) は群の閉包計算。[E_c,E_c] は全交換子 [(x,0),(y,0)](x,y ∈ G; Z 中心なので z,w に依らない)が生成する部分群。

### 1.6 証明書の健全性と完全性

**定理 1.6.** 有限群 G について次は同値:
(a) B₀(G) ≠ 0;
(b) ある e ≥ 1 と正規化コサイクル c ∈ Z²(G, ℤ/e) が存在して、(ii) ι[c] ≠ 0(補題 1.5 のいずれかの形)かつ (iii) すべての可換対 (a,b) について c(a,b) ≡ c(b,a) (mod e)。

証明. (b)⇒(a): 補題 1.4 により res_A ι[c] = 0 for all bicyclic A、補題 1.5 により ι[c] ≠ 0。ゆえに 0 ≠ ι[c] ∈ B₀(G)。(a)⇒(b): e := exp M(G)、B₀(G) の非零元 ξ を取る。§1.2 より ι は全射なので ξ = ι[c] なる c ∈ Z²(G,ℤ/e) があり、正規化できる(任意の 2-コサイクルは正規化コサイクルとコホモロガス)。(ii),(iii) は補題 1.4, 1.5 の逆向き。∎ 〔高〕

注意: (iii) は「bicyclic」の元定義に忠実である。「全アーベル部分群で取っても同じ」(Bogomolov)は一切使わない。

## 3. 検証器

### 3.1 手順とコスト(n = |G|)

| 段 | 内容 | コスト | 根拠 |
|---|---|---|---|
| (0) | `mult` が群表: 単位元・ラテン方陣性・結合律 | O(n³) | 定義 |
| (i) | 正規化 + コサイクル恒等式 c(g,h)+c(gh,k) ≡ c(g,hk)+c(h,k) (mod e) 全三つ組 | O(n³) | 定義 |
| (ii-a) | 補題 1.3(b) の系が非可解(E = e·exp G、exp G は表から計算) | SNF: 方程式 m 本・未知数 n 個の整数行列 | 補題 1.3, 1.5 |
| (ii-b) | E_c の導来部分群を閉包で計算し Z との交わりを見る | O(n²) 個の交換子 + 閉包 O(|D|·|gens|)、|D| ≤ e·n | 補題 1.5 |
| (iii) | 可換対 (a,b) すべてで c(a,b) ≡ c(b,a) | O(n²) | 補題 1.4 |

(ii-a) の方程式本数: 全系なら m = n²。縮約系(既定)は m = |S|·n、S は検証器が表から貪欲に取った生成系:

**補題 3.1.** d := δF − (E/e)c は Z²(G, ℤ/E) の正規化コサイクル。S が G を生成し、d(s,h) = 0 for all s ∈ S, h ∈ G なら d ≡ 0。
証明. コサイクル恒等式 d(g,s) + d(gs,h) = d(g,sh) + d(s,h) より d(gs,h) = d(g,sh) − d(g,s)。g の語長についての帰納法で d(g,·) ≡ 0。∎ 〔高〕
ゆえに縮約系の可解性は全系の可解性と同値。検証器の `full := true` で全系も走らせられる(位数 64 で実測 4.6 秒 vs 縮約 0.1 秒、結果一致)。

(ii-a) と (ii-b) は独立した二つの判定で、両方走らせて一致を要求する(一方の実装バグへの保険)。

### 3.3 信頼境界 — 検証器が**信用しないもの**

- G の pc 表示・collection: 検証器は `mult` を群の定義として受け取り、群であることを (0) で自分で確かめる。
- Schur 被覆・Schur 乗数のアルゴリズム(GAP core `EpimorphismSchurCover`、polycyclic `SchurExtension`)、HAP の `BogomolovMultiplier`、非アーベル外積 G∧G・G⋏G、Eick–Nickel の nilpotent quotient: **一切参照しない**。
- Moravec の公式 B₀ ≅ M/M₀、Bogomolov の「アーベル部分群で十分」: 使わない。
- e が exp M(G) の倍数であること: 健全性には不要(完全性のみに関わる)。

検証器が**信用するもの**: 整数演算、自前の Smith 標準形(GAP core `SmithNormalFormIntegerMatTransforms`)、および §1 の補題(初等的・本文に証明あり)。(ii-b) は SNF に依らない独立判定なので、SNF への信頼も二重化されている。

### 3.4 残る別の信頼点: ラベル ↔ 表

「B₀(SmallGroup(64,149)) ≠ 0」という**ラベル付き**言明にするには、`mult` が SmallGroup(64,149) の群表であることが要る。これは証明書の主張とは独立の同定問題で、選択肢は (a) `IdGroup` を信用する、(b) 追加証明書として pc 生成元の像(表の元番号)を与え、pc 関係式の成立と生成性(閉包が n 個)を検証器が確かめる(コスト O(n·#関係式))。本日の証明書は (a)。〔高〕

## 4. 生成側(証明書の作り方)— 検証の健全性には無関係

Schur 被覆 π: S → G(M := Ker π ≤ Z(S) ∩ [S,S]、M ≅ M(G))を polycyclic の Schur 拡大 F/[R,F] から作る(`PcSchurCover`、§4.3)。

**命題 4.1(transgression).** 中心拡大 1 → M → S → G → 1 の 5 項完全列 H₂(S) → H₂(G) →δ M → S^{ab} → G^{ab} において、M ≤ [S,S] なら δ は全射、さらに |M| = |M(G)| なら δ は同型。〔高〕(完全性から Im δ = Ker(M → S^{ab}) = M ∩ [S,S] = M。)

**命題 4.2(bicyclic の像).** A = ⟨a,b⟩ ≤ G(ab = ba)、ã, b̃ ∈ S を持ち上げとする。δ_G( Im(H₂(A) → H₂(G)) ) = ⟨[ã,b̃]⟩。
証明. δ の自然性より δ_G ∘ H₂(incl) = δ_A(Ã := π⁻¹(A) の拡大 1 → M → Ã → A → 1 の transgression)。Im δ_A = M ∩ [Ã,Ã] = [Ã,Ã](Ã/M = A 可換)= ⟨[ã,b̃]⟩(Ã = ⟨ã,b̃⟩M、M 中心)。∎ 〔高〕

系: M₀(G) := Σ_{A bicyclic} Im(H₂(A) → H₂(G)) は δ_G で K := ⟨[x,y] : x,y ∈ S, [x,y] ∈ M⟩ に移り、Hom(M(G)/M₀(G), ℚ/ℤ) = B₀(G)(双対性; §1.1 と制限写像の双対が H₂ の包含写像であること)。よって **B₀(G) ≅ M/K** で、`B0ViaSchurCover` はこれを計算する。〔高〕

**証明書の構成.** M/K の独立生成元の一つ z(位数 e)への射影 χ: M → M/K → ℤ/e、切断 s: G → S(s(1) = 1)、c(g,h) := χ(s(g)s(h)s(gh)⁻¹)。これは正規化 2-コサイクルで、その E_c は S/Ker χ の押し出しに他ならない。(iii) は K ⊂ Ker χ から、(ii) は χ ≠ 0 かつ δ 同型から従う。〔高〕

計算削減(生成側のみ): K の生成元は a を共役類代表、b を C_G(a) の生成系に限って良い。[ã, b̃₁b̃₂] = [ã,b̃₂][ã,b̃₁]^{b̃₂} = [ã,b̃₁][ã,b̃₂](M 中心)と [ã^g, b̃^g] = [ã,b̃] による。〔高〕`allpairs := true` で |G|² 対を文字通り走る版もあり、位数 64・243 の非自明群で一致を確認(ログ `allpairs` 行)。

### 4.3 pc 被覆の作り方(polycyclic)
Ĝ := F/[R,F](`SchurExtensionEpimorphism`)、N := R/[R,F](中心・有限生成アーベル)、T := N の捩れ部分群 = (R ∩ [F,F])/[R,F] ≅ M(G)(Hopf)。N/T は自由アーベルなので、その ℤ-基底の逆像で自由補空間 L(N = T ⊕ L)を取り、S := Ĝ/L、M := TL/L ≅ T。M ≤ [S,S] は T ≤ [Ĝ,Ĝ] から。走行時に |M| = |M(G)|(GAP core の `AbelianInvariantsMultiplier`、別アルゴリズム)、中心性、M ≤ [S,S] を検査している。位数 128 で 1 群あたり数十ミリ秒。〔高〕

## 5. 逆方向 「B₀(G) = 0」の証明書

### 5.1 なぜ難しいか
「B₀ ≠ 0」は存在言明(一つの類を見せればよい)だが、「B₀ = 0」は H²(G,ℚ/ℤ) の**すべての**非零類が何らかの bicyclic で検出される、という全称言明。有限データにするには H²(G,ℚ/ℤ) 全体を押さえる必要があり、そこに「H² を全部見た」ことの証拠が要る。

### 5.2 何が有限証明書になるか
補題 1.4 により、写像

  Φ: H²(G, ℚ/ℤ) → ⊕_{(a,b) 可換対} ℚ/ℤ, [c] ↦ ( c(a,b) − c(b,a) )_{(a,b)}

は well-defined で、**B₀(G) = Ker Φ**。よって B₀ = 0 ⟺ Φ 単射 ⟺ |Im Φ| = |H²(G,ℚ/ℤ)| = |M(G)|。

証明書: e(exp M(G) の倍数)、正規化コサイクル c₁,…,c_k ∈ Z²(G,ℤ/e)、(主張)「ι[c₁..c_k] が H²(G,ℚ/ℤ) を生成する」。検証器は ω_i := (c_i(a,b) − c_i(b,a))_{(a,b)} ∈ (ℤ/e)^{P} が生成する部分群の位数を SNF で計算し、|M(G)| と比較する。可換対 P は a を共役類代表・b を C_G(a) の生成系に縮約できる(ω が b について加法的: 補題 1.4 の証明の交換子計算から)。〔高〕

**注意(要求仕様への訂正).** 「基底の各元ごとに制限が非自明な bicyclic 部分群を一つずつ示す」だけでは**不十分**。ω_{c₁} = ω_{c₂} ≠ 0 なら各々に証人があるが c₁ − c₂ ∈ B₀。必要なのは各元の証人ではなく Φ の像の位数(= 対形式行列の SNF)。〔高〕

### 5.3 消えない信頼点と、それを消す原理的方法
上の証明書は「c_i が H²(G,ℚ/ℤ) を生成する」を、|Im Φ| = |M(G)| という形で **|M(G)| の値**に預けている。|M(G)| は Schur 乗数アルゴリズム(GAP core / polycyclic / HAP)の出力で、これが唯一の外部信頼点。二つの独立実装(GAP core `AbelianInvariantsMultiplier` と polycyclic `SchurExtension` の捩れ部分)の一致で縮小はできるが消えない。

原理的には消せる: H²(G,ℤ/|G|) は表だけから線形代数で計算できる(Z² = コサイクル恒等式の解空間 ⊂ (ℤ/|G|)^{n²}、B² = コバウンダリ像、H²(G,ℚ/ℤ) = H²(G,ℤ/|G|)/β(Hom(G,ℚ/ℤ)) で Hom(G,ℚ/ℤ) も表から計算可)。コストは n² 未知数・n³ 方程式の ℤ/p^k 上の SNF で、n = 64 でも 4096 未知数・262144 方程式 — 可能だが重い(分〜時間のオーダー、未実測〔低〕)。実用上は |M(G)| を信頼点として明記する方が正直。

### 5.4 M₀ = M との関係
B₀ = 0 ⟺ M₀(G) = M(G)(§4 の双対性)。§5.2 の証明書は「Φ の像が H² 全体」= 「bicyclic からの H₂ の像が M(G) 全体」を言っており、これが M₀ = M の有限証明書である。
